# Contributing

1. Pick the smallest contribution that fits your evidence: a new solution profile, an update to an existing one, a comparison page, or a watchlist entry.
2. Use [templates/system-profile.md](templates/system-profile.md) for any new solution.
3. Use primary sources (official docs, official repos, or verified hands-on use) for every claim. Mark unverified fields as `Unknown` instead of guessing.
4. When adding or updating a core solution profile, link it from [solutions/README.md](solutions/README.md) and, if relevant, from [comparisons/chooser.md](comparisons/chooser.md) so readers can find it through the main decision paths.
5. Open a PR with your sources and any known limitations.
