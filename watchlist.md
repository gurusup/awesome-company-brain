# Watchlist

Solutions that look promising for the company-brain space but do not yet have a full [solution profile](solutions/README.md), because they haven't been evaluated against primary sources yet.

| Solution | Why it's on the watchlist |
|---|---|
| Stack Overflow for Teams (OverflowAI) | Q&A-native format for internal knowledge; worth comparing against wiki-first tools once verified. |
| Bloomfire | Knowledge engagement platform aimed at cross-team knowledge sharing; needs verification. |

Early-stage; needs verification before a full profile. |
| Honcho / Hindsight (org context) | Genuine multi-tenant memory infrastructure (workspaces, peers, sessions / memory banks), but both explicitly position themselves as developer/application memory infra rather than an end-user company-knowledge product — team governance is DIY. Worth a profile if used as a company-brain building block. |
| [Mem0](https://mem0.ai) | Widely referenced hosted+OSS memory layer across multiple awesome-memory lists (IAAR-Shanghai/Awesome-AI-Memory, topoteretes/awesome-ai-memory). Like Honcho/Hindsight, it's personal/application-scoped agent memory infra rather than a team/company-knowledge product with its own governance — worth a profile only if evaluated specifically as a company-brain building block, not as a turnkey product. |
